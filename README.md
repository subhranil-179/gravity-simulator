# Gravity Simulator

## Steps to Run

1. `uv sync`
2. `uv run gravity`

## Custom Simulation

To create custom simulation, the Simulation, Space, Body classes can be used.
Constants can be udpated easily. Currently G constant is set to much lower, must be commeted out for real simulations.
For real simulations, scale_down can be used to properly scale down large measurements.
